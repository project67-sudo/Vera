# VERA — Milestone 2 Repository Guide

This repository contains the VERA AI-Powered News Verification System mini-project.

## Recommended layout

```text
README.md                  Main GitHub project overview
CHANGELOG.md               Dated project progress
.gitignore                 Excluded local and sensitive files
.env.example               Environment variable names (no secrets)
VERA-main/Project_Vera/    Flask application and source code
prompts/v1/                Version 1 development prompts
prompts/v2/                Version 2 development prompts
prompts/v3/                Version 3 development prompts
prompts/final/             Final prompts used by the project
test-data/                 Test inputs and recorded outputs
docs/                      Diagrams, Milestone 2 PDF and supporting documents
```

## Milestone 2 checks

- [ ] Verify that all application source files and dependencies are present.
- [ ] Add prompt files for each version and final prompt sheets.
- [ ] Record at least three meaningful prompt iterations, their changes and observed results.
- [ ] Add at least ten test cases, including at least three edge cases, with actual outputs.
- [ ] Add diagrams and the Milestone 2 PDF under `docs/`.
- [ ] Confirm the prototype link and reel link are accessible.
- [ ] Confirm that the README contains the team members and a working prototype link.
- [ ] Verify no real API keys, passwords, or personal account databases are committed.

**Note:** This checklist is a plan, not a claim that all files or tests have been uploaded or completed. Do not mark a module Working unless tested.

## Running the project

Follow the instructions in [README.md](README.md). The Python source files are expected under `VERA-main/Project_Vera/`; verify their presence before evaluation.
